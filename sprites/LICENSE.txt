Sprite attribution
==================

All PNG files under this directory (mon/, hero/, item/) are tiles from
Dungeon Crawl Stone Soup (DCSS), copied unmodified (pixel data unchanged;
only file names under mon/ were changed to this game's monster ids).

Source repository : https://github.com/crawl/crawl
Source path       : crawl-ref/source/rltiles/
Commit            : cf743e747503946a7456dcd18b451793e1b76895
Retrieved         : 2026-10-03

License of the tiles
--------------------
From the DCSS repository root file LICENSE:

  "The majority of Crawl's tiles and artwork are released under the CC0
   license (https://creativecommons.org/publicdomain/zero/1.0/), and new
   submissions are under this license unless otherwise specified. However,
   the licensing situation may be complex, especially for older pieces. For
   information regarding the licenses of our tiles and artwork, see
   https://github.com/crawl/tiles"

The same file lists among the component licenses: "Public Domain|CC0: most
of tiles, perlin.cc, perlin.h".

From crawl-ref/source/rltiles/license.txt:

  "Part of the graphic tiles used in this program are from the public
   domain roguelike tileset "RLTiles". Some of the tiles have been modified.
   You can find the original tileset at: http://rltiles.sf.net"

The crawl/tiles project (https://github.com/crawl/tiles) maintains a list
of tiles with unclear ownership (TILES_UNDER_UNKNOWN_LICENSE.md). No file
whose name appears on that list was copied here; the three matching names
in the folders copied wholesale (player/hand1/demonblade.png,
item/potion/i-brilliance.png, item/scroll/i-silence.png) were deliberately
left out, and no monster tile on that list was selected.

CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/
Credits for the artists: https://github.com/crawl/crawl/blob/master/crawl-ref/CREDITS.txt
and https://github.com/crawl/tiles/blob/master/ARTISTS.md

item/weapon/greatsword2.png on a solid background.
